# Learning GapFinder: start here

These pages explain GapFinder from the beginning, in plain words. You don't need to know anything about
the project to start. Read them in order; each one takes about 5-10 minutes.

| # | Page | You will learn |
|---|---|---|
| 1 | [What is GapFinder?](01_what_is_gapfinder.md) | the problem it solves, with a simple story |
| 2 | [Using GapFinder](02_using_gapfinder.md) | how to run it, what you give it, what you get back, how to read the report |
| 3 | [The big picture](03_architecture_overview.md) | the main parts and how data flows between them |
| 4 | [Inside each part](04_components_deep_dive.md) | what every component does and how |
| 5 | [Why it's built this way](05_design_decisions.md) | the important choices, and what we chose not to do |
| 6 | [How we test it](06_how_we_test_it.md) | the benchmark, the sealed tests, and how to read the numbers honestly |
| 7 | [The journey](07_the_journey.md) | how the project grew, version by version: what was wrong, what changed, what improved |
| 8 | [Limits and what's next](08_limits_and_next.md) | what it can't do yet, and the plan |
| 9 | [Glossary](09_glossary.md) | every special word, explained in one or two lines |

**One example runs through all the pages:** the MC Dropout paper (Gal and Ghahramani, 2016). Its code
gives different numbers from the paper, and we know why, because the authors later explained it. That
makes it a good way to see what GapFinder does.

If a word is new to you, look it up in the [glossary](09_glossary.md).
